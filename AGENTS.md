# Kofi — Contexto manual

El usuario proporciona manualmente el contexto y las instrucciones necesarios para cada encargo.

No cargar automáticamente la constitución, AI Context, especificaciones, tracker ni contratos de diseño. Consultarlos cuando el usuario los aporte o solicite.

Las políticas anteriores del repositorio quedan retiradas: no imponen etapas, aprobaciones adicionales, límites por perfil, ciclos Git, secuencias de skills, actualizaciones documentales ni controles obligatorios. Las skills se usan según el encargo y el contexto de la conversación.
